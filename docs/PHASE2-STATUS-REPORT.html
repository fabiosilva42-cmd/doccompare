3. Bugs Found & Fixed in the Inherited Codebase

During pre-implementation health checks and full-application testing, the following defects (present in the code as received) were identified and fixed:

DefectSeverityImpact before the fix
Notifications could not be marked as read / deleted (broken SQL helper)Critical Mark-as-read and delete crashed on the real backend; unread counter silently always showed 0. Hidden by demo mode.
PDF text extraction failed for every PDF (pdf-parse v2 API mismatch)Critical All uploaded PDFs — the platform's primary document format — silently produced no text for AI analysis.
EAN-13 check digit algorithm invertedCritical Valid EAN-13 barcodes were reported to the AI as invalid (and invalid ones as valid). DUN-14 was unaffected by parity coincidence. Fixed with regression tests.
Result links used the wrong identifier on 4 pages (Dashboard, History, Kanban, Notifications)High Opening a result from those pages failed against the real API. Backend now resolves both identifier types.
SQL scoping bug in order-list subqueriesHigh Counts could resolve against the wrong table scope; new aggregate fields errored until qualified.
5 TypeScript compilation errors (wrong import path in both locale files, circular type, wrong error type, unused variable)Medium tsc failed; type safety was broken for the i18n and mock layers.
Obsolete database seed with 5 outdated AI promptsMedium Running it would have corrupted the prompt set (correct seeding is the 3-prompt setup endpoint). File removed.

6. Recommended Backlog (pre-existing, outside Phase 2 scope)

  • Access-control hardening: order list currently returns all users' orders; results are readable by anyone holding the identifier; admin pages are hidden but not route-guarded in the frontend. Recommended as a priority security item.
  • Credential rotation: older repository documents contain live-looking credentials (API key, database passwords, SSH details, default admin). These should be rotated before wider distribution.
  • Localization completion: the Result and Divergences pages plus legal pages remain untranslated (translation keys already exist for most of them).
  • Code quality: 48 pre-existing lint findings (loose types etc.); frontend bundle could benefit from code-splitting (1.5 MB).
  • Preferences enforcement: notification opt-out toggles are saved but not yet consulted by the email sender.
